# 安装、升级与卸载

## 下载安装

从 [GitHub Releases](https://github.com/ZeroClian/stockbar/releases/latest) 下载 **Tickfin 1.2.5**。旧版 v1.1.0 的应用名为「自选股」，升级时请先退出旧应用。

| 文件 | 用途 |
| --- | --- |
| `Tickfin-<版本>-arm64.dmg` | 推荐；打开后将「Tickfin」拖入 Applications |
| `Tickfin-<版本>-arm64.zip` | 解压后手动移动应用 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

仅发布 Apple Silicon（M 系列芯片）版本。部署目标 macOS 13+；最低版本与 Intel 未实机验证。不要将 arm64 安装包当作 Universal 包。

DMG 内的 Applications 是安装目标快捷方式。复制完成后弹出映像，从应用程序文件夹启动。菜单栏出现单色鱼形 K 线标记，无 Dock 图标；点标记打开面板，偏好页可退出。

## 首次打开被阻止

本版仅 ad-hoc 签名，未使用 Apple Developer ID，未公证。macOS 可能提示无法验证开发者。

确认下载自本项目 Release 并核对校验值后，尝试打开一次，再到「系统设置 → 隐私与安全性」找到对应应用提示，按系统提供的「仍要打开」流程操作。不同 macOS 的文字可能有差异。不要关闭 Gatekeeper，也不要运行来源不明的修复脚本。

如果系统明确报告恶意软件、下载损坏或校验不一致，停止安装并反馈，勿绕过。具体说明见 [Apple 官方支持](https://support.apple.com/102445)。

校验单个下载包（将文件名改成你下载的版本）：

```bash
shasum -a 256 Tickfin-1.2.5-arm64.dmg
```

与同一个 Release 中 `SHA256SUMS.txt` 的对应行比较。如果下载了所有包，可在同目录运行 `shasum -a 256 -c SHA256SUMS.txt`；只下载其中一个时，其他文件缺失属于预期。

## 单项提醒设置（v1.2.3）

自选项 → 提醒包含“涨跌幅 / 价格 / 盈亏 / 设置”四页。前三页编辑条件，“设置”统一配置本自选项三类提醒共用的通知方式；改动后点击保存。v1.2.5 起，触发规则统一在偏好 → 提醒通知中查看。

## 偏好分类（v1.2.3）

偏好首页提供显示与快捷键、行情刷新、提醒通知、Bark 推送、版本更新、使用说明与数据六个入口。点击进入单独页面，左上角返回分类首页；Bark 内分“连接”和“模板”，更改后点击保存。图表读法、操作和计算说明统一放在“使用说明与数据”中按需展开，面板仍保持窄宽度，长内容可滚动。全局、面板内和文本编辑快捷键统一列在“显示与快捷键”页，无需展开，触发规则、通知方式说明和通知测试位于“提醒通知”。

## 面板内快捷键（v1.2.3）

全局快捷键打开面板后，可直接用以下按键，无需鼠标。仅 Tickfin 面板处于前台时生效。按 ⌘K 可随时查看完整快捷键清单。

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 在当前自选或持仓列表选择，自动滚动到选中项 |
| 回车 / → | 查看选中股票详情 |
| ⌘1 / ⌘2 | 切换自选 / 持仓列表 |
| ⌘3 | 打开当前股票提醒设置 |
| 空格 / ⌘D | 显示 / 隐藏名称和持仓金额 |
| ← / ⌘[ | 返回；设置子页返回分类首页 |
| ⌘F | 搜索添加股票或 ETF |
| ⌘R | 手动刷新，休市也可使用 |
| ⌘I / ⌘, | 未读提醒 / 偏好设置 |
| ⌘回车 | 将列表选中项设为状态栏关注项 |
| ⌘K | 查看所有快捷键及全局快捷键设置 |
| ⌘S | 保存单项持仓 / 提醒编辑 |
| Esc | 立即收起并恢复隐私遮罩 |

方向键、空格、回车在输入框内保持文本编辑功能；复制粘贴不受影响。录制全局快捷键时暂停面板快捷键。浏览列表不自动改变状态栏关注项。切换页面会放弃未保存的编辑，可先按 ⌘S 保存；涉及删除的操作没有新增快捷键。

## 全局快捷键

偏好 → 显示与快捷键 → 全局快捷键 → 点击设置，按下组合键并松开主按键保存；再次点击可改键，「清除」停用。建议使用 ⌃⌥空格；若被占用可换其他组合。至少两个修饰键，包含 ⌃ 或 ⌘，主按键为字母、数字、空格或左右方向键；不接受单键、仅修饰键或显式 Fn 组合。方向键自带的 Fn 标志不影响录制。

可分别设置“打开／收起”“上一只”“下一只”三组快捷键，不可重复。打开／收起使用同一组合键，收起恢复遮罩；上一只／下一只按自选顺序循环切换状态栏关注项，不展开面板。录制中 Esc 取消；按已有快捷键仅结束录制。默认不占用任何组合键。设置在本机保存，应用运行期间才生效，不需要辅助功能或输入监控授权。

系统快捷键及其他已注册全局组合会检测冲突；其他应用的菜单／内部快捷键无法穷尽检测，请避免常用组合。按物理键位记录，界面使用美式字母标识；切换非美式键盘布局时位置不变。若重启时被其他应用占用，偏好页显示不可用，需重新设置；原设置仍保留。

## 刷新与后台提醒

偏好 → 行情刷新，设置 5–300 秒整数并保存；此间隔也决定提醒采样频率。关闭面板不会停止后台监测，静默小点、系统通知或 Bark 仍按已保存规则生效。休眠和退出会停止监测。

休市（午休、周末和内置节假日）暂停自动行情请求，开市恢复。v1.2.3 支持随时手动刷新：点击主页刷新图标，或偏好 → 行情刷新 → 立即刷新；休市时获取最新可用报价但不触发提醒；手动添加股票的代码验证仍会查询接口。休市重启显示上次缓存，若此前未生成缓存则等待开市。日历当前覆盖 2026 年，超出范围会显示“日历需更新”并暂停监测，需升级含新日历的应用。

主页图钉可切换关注股票；上下箭头可调整自选顺序。选择关注股票不会自动改变“仅图标”隐私模式。

## 升级

从 1.2.1 起：偏好 → 版本更新 → 检查更新 → **立即更新**。应用自动下载适配芯片的正式版 ZIP，校验 SHA-256、应用标识、版本、签名和架构，退出旧进程后在原位置替换并重启。新版启动确认后删除下载 ZIP、解压目录、更新助手和旧应用；失败时保留或恢复旧版并清理本次临时文件；若回滚本身失败，会保留恢复所需备份。持仓与设置数据保留。只在用户点击后更新，不会在后台擅自安装。

更新准备期间普通退出会暂缓，待更新助手接管后自动重启；请勿强制结束进程。强制退出、断电或目录失去写权限时可能留下恢复文件，不保证完成自动清理。

请只保留一个安装副本，放在 `/Applications/Tickfin.app`（推荐）或 `~/Applications/Tickfin.app`，并确保该位置可写。不要从下载目录、DMG 或多个构建目录长期启动；复制安装后删除下载或解压的多余副本并弹出 DMG。偏好中的“显示当前应用位置”可核对正在运行的副本。应用内更新不会额外留下下载包。

旧版 1.2.0 仍需点击“下载新版”打开 GitHub Release 后手动替换；升级到支持一键更新的版本后即可使用新流程。发布包缺少校验信息或不适配芯片时仍提供手动下载入口。

1. 从应用偏好页退出，避免两份应用同时写同一数据文件。
2. 如需备份，复制 `~/Library/Application Support/StockBar/state.json` 到自己的安全位置。
3. 将 Tickfin.app 放入 Applications，选择替换原应用，再启动。由旧版「自选股.app」升级时，先退出并删除旧应用包；不要删除 Application Support 中的数据目录。

Tickfin 沿用原 bundle identifier 和 `~/Library/Application Support/StockBar` 数据目录，保留自选、持仓、提醒与快捷键设置；不用手动搬迁数据。

1.1.0 保留 1.0.x 自选、股数、成本、阈值与去重记录，默认改为图标状态栏、代号和静默提醒。系统通知可按股票重新主动选择。新版本数据不保证可被旧版本读取，降级前先保存并使用对应旧备份。

## Bark 手机与手表通知

1. 在 iPhone 安装 [Bark](https://github.com/Finb/Bark)，允许通知。复制其完整推送网址，例如 `https://api.day.app/设备密钥/内容`。v1.2.3 可在 Tickfin 点击“从剪贴板导入”，或将网址粘贴到遮罩的完整网址框后点击“导入网址”，再启用并保存。自建服务若有路径前缀，请仍分别填写完整服务地址和密钥。
2. Tickfin → 偏好 → Bark 推送，填写服务地址和密钥，开启并保存。可使用自建 HTTPS Bark 服务；地址不带密钥、登录信息或查询参数。
3. v1.2.3 的通知标题自动使用触发规则，固定区显示真实股票名称和规则，不再显示行情时间；补充说明可以编辑。v1.2.3 打开“发送阈值和触发数值”才发送具体数值。v1.2.4 改为固定发送阈值和触发数值，盈亏规则按金额或百分比显示；非价格提醒同时发送当前价格，无需重新保存旧配置。模板不支持替换固定字段或执行变量表达式。
4. 保存后点击“发送测试”。v1.2.3 的测试明确标为“测试通知”，使用当前状态栏关注项的代码与价格，缺失字段显示 xxxx；不代表实际触发，不消耗每日提醒次数。Bark 接收成功不代表手表已经显示。
5. 到每只自选项 → 提醒 → 设置，将“提醒方式”改为“Bark 推送”。未选择的自选项沿用原提醒方式；成功推送同时保留本机未读提醒。
6. 在 iPhone 的 Watch App → 通知中开启 Bark 镜像。iPhone 锁屏、手表佩戴且解锁时通常在手表显示；声音、触感及专注模式遵循设备设置，参见 [Apple 通知说明](https://support.apple.com/zh-cn/108369)。相同 Apple 账号本身不会转发 Mac 通知。

Bark 默认关闭，密钥仅保存在本机钥匙串。v1.2.3 打开设置不读取密钥；保存后仅在当前进程内缓存，测试和后台推送不允许弹出授权框。重启后会尝试无交互读取；若系统要求重新授权，推送暂停并提示进入连接页点击保存。删除密钥属于显式更新操作，也可能请求系统授权。清空密钥输入框表示保留已保存密钥；“删除密钥并停用”会停止 Bark 推送，保留自选、持仓和提醒规则。全局关闭 Bark 时，已选 Bark 的规则暂停推送，不会自动改成系统通知。

Mac 必须运行且未休眠；面板收起不影响交易时段内监测。只有服务返回成功才写入每日去重；失败至少等待 60 秒，再对仍满足规则的新鲜行情重试，不补发已过时提醒。如果服务已接收但网络响应丢失，重试仍可能重复，无法保证端到端恰好一次。通知内容会经过所配置服务，设备密钥和完整推送网址请勿公开。

## 常见问题

- **找不到窗口**：这是菜单栏应用。看右上角鱼形 K 线标记，或再次打开应用。刘海屏菜单项过多时可能被系统隐藏。
- **为什么没有通知横幅**：默认是静默小点。主动改为系统通知后，还需检查系统通知权限与专注模式。
- **金额是圆点**：点眼睛显示。收起面板后自动恢复隐藏。
- **行情带「旧」**：报价过期、非当日或更新失败；旧行情不会触发提醒。休市时不会模拟新数据。
- **添加不了股票或 ETF**：可输入六位交易代码（如 `300750`、`510300`、`159915`）或拼音首字母（如 `NDSD`），最多显示 5 条候选，点击右侧“＋”添加。不支持指数、LOF、场外基金或中文全名搜索。搜索接口不可用时可尝试完整代码查询。
- **数据文件损坏**：应用停止写入和提醒以保护原文件；先退出并备份，再用自己确认有效的备份恢复，不要随意删除持仓文件。

## 卸载

从偏好页退出，删除 Applications 中的「Tickfin」。这不会删除持仓。若确认不再需要，先备份，再手动移除 `~/Library/Application Support/StockBar`；该操作不可恢复未备份数据。
