# 使用指南

[返回首页](../README.md) · [安装与升级](INSTALL.md)

## 提醒规则

上涨达到正阈值、下跌达到负阈值即可触发，不要求刚刚穿越阈值。相同股票、方向、阈值每天一次，重启保留记录；改阈值视为新规则。静默提醒将未读与去重记录一起保存，标记已读不会重触发；下一交易日的新提醒会清理以前的未读。

在上海时区交易日 09:30–11:30、13:00–15:00 内刷新（不含收盘端点），且报价为当日、不超过 180 秒的新行情时判断。**关闭面板仍持续监测，应用必须保持运行，电脑不能休眠。** 提醒按刷新间隔采样，可能错过两次采样之间短暂触达阈值的情况。

午休、收盘、周末和内置节假日停止自动行情刷新，开市自动恢复；休市启动只读取上次行情缓存，无缓存时等待开市。点击主页刷新图标或偏好 → 行情刷新 → 立即刷新可随时请求最新可用行情，休市不触发提醒；手动添加股票时仍会查询接口验证代码，版本检查由用户单独触发。休眠、退出、旧行情、更新失败不触发提醒。

内置日历依据[上交所 2026 年休市公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)，覆盖 2026 年，周末调休上班也不开市；不包含临时停市。超出已覆盖年份会暂停行情监测并显示“日历需更新”，需安装包含新年度日历的版本。旧版 v1.1.0 采用固定 15 秒轮询和新鲜行情过滤，不含该调度策略。

主动选择系统通知后，通知使用代号、无金额、无声音；横幅受通知权限和专注模式影响。系统通知提交成功后才保存去重记录，通知系统与本机文件之间不是跨系统原子事务。

## 操作入口

- **面板内快捷键**：↑↓ 选股、回车查看，⌘1 / ⌘2 切换自选 / 持仓，⌘3 提醒，⌘R 手动刷新，⌘S 保存单项编辑。按 ⌘K 打开“显示与快捷键”完整清单；输入框保留普通文本编辑功能。[全部按键](INSTALL.md#面板内快捷键v123)。

- **全局快捷键**：偏好 → 显示与快捷键 → 全局快捷键 → 点击设置，按组合键并松开后保存。默认未设置；支持至少两个修饰键（包含 ⌃ 或 ⌘）加字母、数字、空格或左右方向键，例如 ⌃⌥空格。
- **刷新间隔**：偏好 → 行情刷新 → 输入 5–300 秒整数 → 保存。
- **自选排序**：主页右上角上下箭头 → 点每行上移／下移，即时保存；持仓列表沿用自选顺序，代号不变。
- **快速切换状态栏股票**：主页右上角图钉 → 选择代号。保持原状态栏显示模式；如需看涨跌幅，到偏好将“仅图标”改为“仅涨跌幅”或“涨跌幅＋现价”。
- **检查新版**：偏好 → 版本更新 → 检查更新 → 立即更新。首次从 v1.2.0 升级需手动替换一次，此后支持应用内更新。
- **使用说明**：偏好 → 使用说明与数据，按需展开自选操作、图表读法及持仓计算；提醒规则与通知方式在偏好 → 提醒通知中查看。操作页只保留必要的标签、状态和反馈。

## 功能详解

**当日走势（v1.2.5）**：点击自选项后直接使用“分时 / 5 分钟 K / 持仓 / 提醒”四个切换，默认分时。分时按分钟显示当天已发生的行情，5 分钟 K 每根包含对应区间的开盘、最高、最低、收盘价；沪深股票与 ETF 的完整交易日通常为 48 根。数据由历史接口回补，下午打开也可看到上午走势，尚未发生的时段留空；午休分段，09:30–11:30、13:00–15:00 以外的数据不绘制。

详情面板在同一隐私显示状态下保持固定可见高度，四个页签共用顶部数字网格；切换及数据加载不会改变切换栏的位置和宽度。正常可用空间下，隐藏持仓时为 280×350pt、显示持仓时为 280×370pt；屏幕空间不足时随可用高度缩小，较长内容可在面板内滚动。

鼠标悬停或点击图表时，上方数字区同步显示该点价格、涨跌幅和时间；下方左右按钮可逐点浏览，“最新”恢复跟随最后一个数据点。分时两侧保留当日最高、最低价，补充昨收与涨跌额；K 线复用为该根最高、收盘、最低价，另显示开盘价、昨收及涨跌幅。图表下方不重复数值。红色空心 K 表示收涨，绿色实心 K 表示收跌，时间旁同时说明涨跌；最后一根区间尚未结束时标注“形成中”。股票价格两位、ETF 三位小数。

“价位线”展示已保存的涨到 / 跌到价格及涨跌幅换算价位，涨跌幅以图表对应交易日的昨收价换算。开启隐私显示后，数量和成本有效的持仓另显示成本线；隐藏后同时移除成本线与其说明。图区之外的价位在图例中用 ↑ / ↓ 标记，不为远处阈值压缩走势。点击“设置提醒”可编辑规则，保存后更新价位线。

图表首次打开、切换分时 / K 线或点击上方刷新图标时请求数据；查看期间按不低于 15 秒的设置间隔更新，休市暂停自动请求，收起面板或切换到持仓 / 提醒即取消。休市可能显示上个交易日，上方注明完整日期及“历史”，价格、高低价、昨收均与图表对应同一交易日，不使用其他日期的缓存补数。悬停结束回到点击选中的点或最新点，刷新回补保留选中时间，切换类型或交易日重置为最新。请求失败时保留本次查看期间已有数据并提示重试，不保存额外历史文件，也不使用历史数据触发提醒。数据接口对个别证券可能不提供分钟 K，例如北交所目前的实测响应；无数据时可切换分时查看。

**Bark 推送**：偏好 → Bark 推送 → 连接，导入完整 HTTPS 推送网址或分别填写服务地址和设备密钥，启用并保存；再到自选项 → 提醒 → 设置选择“Bark 推送”。模板标题跟随触发规则，固定显示真实股票名称和规则，不再显示行情时间；补充说明可编辑。v1.2.3 可选择是否发送数值；v1.2.4 正式通知固定包含阈值与触发数值（价格、涨跌幅或持仓盈亏），非价格提醒另附当前价格；旧配置也生效，无需重新保存密钥。打开设置不读取钥匙串，后台推送不弹授权框，需要重新授权时请手动保存。测试使用当前关注项的名称、代码和价格，缺失显示 xxxx，不包含持仓数量或盈亏，也不消耗提醒次数。详见[手机与手表配置](INSTALL.md#bark-手机与手表通知)。

**涨跌幅＋现价（v1.2.2）**：偏好 → 显示与快捷键 → 状态栏 → 涨跌幅＋现价，例如 `+3.00% · 103.00`。沿用当前关注项，切换快捷键同步更新；股票现价两位小数、ETF 三位，旧行情追加“旧”，未取得行情显示“—”。不展示持仓金额或真实名称，原有显示模式仍可选择。

**一键更新**：偏好 → 版本更新 → 检查更新 → 立即更新。自动下载适配芯片的 GitHub 正式版 ZIP，核对 GitHub 资产 SHA-256、应用标识、版本、签名和架构后，在原安装位置替换并重启；新版启动确认后删除下载包、解压目录、助手和旧版本。失败时保留或恢复旧应用；仅当回滚本身失败时保留备份以便恢复。持仓与设置目录不参与替换。应用应安装于 `/Applications/Tickfin.app` 或 `~/Applications/Tickfin.app`，目录需要可写；缺少兼容包或校验信息的发布版会保留手动下载入口。应用同时只运行一个实例。

更新准备期间普通退出会暂缓，待更新助手接管后自动重启；请勿强制结束进程。强制退出、断电或目录失去写权限时可能留下恢复文件，不保证完成自动清理。

**价格与盈亏提醒**：点击自选项 → 提醒 → 选择“价格”或“盈亏”。价格支持涨到／跌到；盈亏按单项持仓的浮动盈亏计算，可选金额或百分比，亏损阈值填正数。例如成本 100 元、100 股，现价 110 元，浮动盈利为 1,000 元 / 10%，与当日涨跌无关。数量或成本为零时暂停盈亏判断；清空持仓会保留规则，重新录入后恢复判断。三类提醒可同时启用，达到或越过阈值即可触发，保存时已达标则在下一次有效行情触发。仍按每条规则每天一次去重，修改单位或阈值视为新规则；盈亏数值在未读提醒中默认隐藏，系统通知不含价格或盈亏金额。

**状态栏切换快捷键**：偏好 → 显示与快捷键 → 全局快捷键，分别设置“打开／收起”“上一只”“下一只”。新增两组默认未设置，可使用至少两个修饰键（含 ⌃ 或 ⌘）搭配 ← / →，也支持字母、数字和空格。按自选顺序循环切换并保存选中项，适用于股票和 ETF；不打开面板、不改变隐私模式。状态栏为“仅图标”时切换不会显示数值，需要时可改为“仅涨跌幅”或“涨跌幅＋现价”。

添加页支持六位证券代码或拼音首字母（不区分大小写，如 `NDSD`、`GZMT`、`HS300`）。输入后自动搜索，优先完整匹配、其次前缀匹配，最多显示 5 条 A 股/ETF 结果，点击右侧“＋”添加；已添加项显示勾选，可连续添加后点击“完成”。搜索需要联网，输入内容会发送给腾讯搜索服务；完整证券代码仍通过行情服务直接查询验证。

持仓与提醒页上方从左到右显示当日最高价、当前价格、当日最低价，当前价格字号略大。股票价格保留两位小数，ETF 保留三位；缺失价格显示“—”，注明行情时间，历史行情的高低价属于该行情日期。查看分时或 K 线后，优先展示其中更新的报价，不将历史数据用于提醒判断。

- 默认代号取名称的拼音首字母，保留英文和数字，最多 8 个字符；重名自动加数字后缀，仍可手动修改。
- 旧版已分配的 `A01` 等编号会迁移为拼音代号，其他自定义代号保留。旧版未记录代号来源，手工设成已分配编号格式的代号也可能被识别为默认值；升级前可备份数据。新版本保存后不再重复迁移手工编号。
- 点击自选项 → 持仓 → **清空持仓** → 确认，仅把该项数量和成本归零，立即保存；自选、代号、提醒、状态栏关注及其他持仓不变。清空后该项仍在自选中。

## 计算口径

| 项目 | 计算方式 |
| --- | --- |
| 每股涨跌额 | 现价 − 昨收价 |
| 当日估算盈亏 | 每股涨跌额 × 当前持仓股数 |
| 浮动盈亏 | （现价 − 平均成本）× 当前持仓股数 |

平均成本可填写券商含费成本；不追踪日内交易、已卖出收益、分红或现金。缺少部分持仓行情时不展示不完整合计；旧行情会标记。金额使用 `Decimal` 计算。ETF 的“股数／每股”对应“份数／每份”；涨跌额显示三位小数，涨跌幅和持仓盈亏仍显示两位小数。沪深上市的跨境 ETF 也按沪深交易时段刷新。

## 数据与隐私

数据位于 `~/Library/Application Support/StockBar/state.json`，包含自选、代号、持仓、提醒及去重记录；本地文件未加密，界面遮罩不等于磁盘加密。应用将最近行情保存在同目录的 `quotes-cache.json`，缓存仅供展示，不触发提醒。更名后沿用 `StockBar` 数据目录，已有持仓和设置无需迁移。

行情通过 HTTPS 请求腾讯公开接口 `qt.gtimg.cn`，发送证券代码；拼音搜索通过 `smartbox.gtimg.cn` 发送输入的查询词。查看图表时另通过 `web.ifzq.gtimg.cn` 和 `ifzq.gtimg.cn` 查询对应证券的分时 / 分钟 K 历史数据，仅发送证券代码与周期参数。上述请求都不发送持仓数量或成本，价位线在本机绘制。服务提供方仍可获知网络请求信息。项目与腾讯、券商没有隶属关系，也不承诺接口长期可用。

主动启用 Bark 后，已选通知内容会经配置的 Bark 服务与 Apple 推送服务发送。密钥保存在本机钥匙串，不包含在 `state.json` 备份中；迁移电脑需重新配置。v1.2.4 的正式通知固定发送阈值和触发数值，可能包含持仓盈亏。请求使用 HTTPS POST，不把密钥放在 URL 中，不跟随重定向；不记录服务端原始错误响应。

备份、升级和卸载步骤见 [安装指南](INSTALL.md)。损坏的数据文件不会被静默重置，应用会停止保存与提醒以保护原数据。
