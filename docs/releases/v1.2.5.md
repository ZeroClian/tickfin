# Tickfin v1.2.5

个股详情现在可以直接查看完整当日分时、5 分钟 K 线和提醒价位。

- **当日分时与 5 分钟 K**：自动回补当天已发生的行情，晚打开也能看到上午走势；午休分段，休市显示最近可用交易日。
- **上方集中读数**：悬停、点击或逐点浏览图表时，上方同步显示价格、涨跌幅、时间及 K 线开高低收，图表下方不再重复数字。
- **提醒价位线**：展示已保存的到价与涨跌幅阈值；主动显示持仓后叠加成本线，隐藏后移除。
- **稳定紧凑的四页切换**：分时 / 5 分钟 K / 持仓 / 提醒共用顶部数字区，修复切换抖动并减少底部留白；说明统一放入偏好，操作页更简洁。
- **本地安装修复**：修复部分 macOS 环境下更新计划生成失败的问题。

## 安装与升级

Apple Silicon / macOS 13+：下载 `Tickfin-1.2.5-arm64.dmg`，或在应用内“偏好 → 版本更新”检查更新。ZIP 用于应用内更新，`SHA256SUMS.txt` 用于完整性校验。保留原自选、持仓、提醒和快捷键设置。

154 项自动化测试通过，六种场景共 1,584 帧原生切换检查通过。已核对公开历史接口和浅深色原生布局；尚未完成真实交易时段长期运行、最低系统版本及完整桌面交互验收。部分证券可能没有分钟 K 数据，可查看分时。安装包采用 ad-hoc 签名，尚未 Apple 公证。
